# ADR-0003：验收工具允许注册低级别鼠标钩子（仅观测，无条件放行）

- 状态：已接受
- 日期：2026-09-19
- 对应原则：P1

## 背景

P1 规定产品代码不注册全局鼠标钩子（见 ADR-0002）。但验收标准 A1 / A3 要求证明
「本程序没有吞掉鼠标消息，因此不会破坏 Wallpaper Engine 的互动壁纸」。这件事的客观证据
只能由一个**自己也在钩子链上的观测者**给出：它记录自己收到了哪些消息，与注入的消息条数比对，
少了就说明链上游有人吞了消息。

## 决策

在验收工具（`tools/HookProbe`）中允许注册 `WH_MOUSE_LL` 低级别鼠标钩子，但必须满足：

1. 只用于观测与计数，钩子函数**无条件 `CallNextHookEx` 放行**，绝不返回非零值；
2. 只存在于 `tools/` 下的验收工具里，**产品代码（`src/`）一律禁止**；
3. 源码中在调用行前两行内标注 `// guard-exempt: <原因>`，说明用途；
4. 工具自身在退出时卸载钩子，不留残留。

## 理由

1. 让「不吞消息」这个承诺可被客观验证，而不是靠肉眼点壁纸说"好像能点"；
2. 观测者与被测者必须是同一类机制，否则证据不成立；
3. 把钩子限制在 `tools/` 且产品代码由 CI 守卫拦截，风险面可控。

## 后果

- CI 守卫仍会扫描 `tools/`，因此工具里的钩子调用必须带 `guard-exempt` 标注，属于有意豁免而非疏漏；
- 跑 `HookProbe` 时桌面上会多一个观测钩子，仅计数、不影响其他程序；
- 若将来有人想把这个钩子搬进 `src/`，守卫会拦下，且必须先修改本 ADR。
